# What the buildfarm builds. One repository-root-relative path per line. A path
# holds either a pixi.toml (a ROS package) or a recipe.yaml. See README.md.
#
# ORDER MATTERS. scripts/build.sh indexes each package that it builds into
# ./local-channel. The workspace reads that channel first. A package can
# therefore build only against the packages above it. Put each package after
# everything that it needs.

# The ethercat_* ROS packages are NOT built yet. Our fork hardcodes
# ETHERLAB_DIR=/usr/local/etherlab, and it puts that path into the
# INTERFACE_INCLUDE_DIRECTORIES of its exported CMake targets. A consumer then
# stops at the generate step with "includes non-existent path
# /usr/local/etherlab/include".
#
# A workstation that has EtherLab installed hides this, because the path exists
# there. Do not trust a local build of these packages. CI is the honest test.
#
# To clear it, patch Berkeley-Humanoids/ethercat_driver_ros2 to find ecrt.h and
# libethercat under $PREFIX. Then move the pin in the manifests, and uncomment
# these lines.
#
# ethercat_manager stays out for a second reason, and it has no manifest. Its
# source calls ::close without an include of <unistd.h>, so it does not compile.
# No product uses it.
